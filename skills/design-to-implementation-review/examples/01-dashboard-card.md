# Example: dashboard insight card

Context:
A dashboard contains four “AI insight” cards in a two-column grid.

Each card includes:
- A small category label, such as “Risk”
- A headline, such as “Revenue concentration has increased”
- Two-sentence explanatory text
- A source count, such as “Based on 12 reports”
- A “View evidence” link

The design shows cards with similar-length headlines and body copy.

Interaction notes:
Selecting “View evidence” opens a right-side panel containing the relevant source reports.

No loading, empty, error, mobile, keyboard, or permissions behaviour is specified.
