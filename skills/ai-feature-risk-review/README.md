# AI Feature Risk Review

A structured review for AI product concepts before design or delivery.

Use it when a feature generates content, recommendations, classifications, decisions, or actions that users may rely on. It is particularly useful when the feature handles sensitive data, influences consequential choices, or could be mistaken for an authoritative source.

## Input

Provide as much of the following as you have:

```md
Product / feature:
Who it is for:
Problem:
Proposed AI behaviour:
Inputs and data sources:
