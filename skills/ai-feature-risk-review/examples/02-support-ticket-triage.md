# Example: support ticket triage

Product / feature:
AI Support Triage

Who it is for:
Customer-support agents handling incoming B2B support tickets.

Problem:
Agents spend time reading, categorising, and routing repetitive requests before they can start resolving them.

Proposed AI behaviour:
The system reads each inbound ticket, proposes a category, urgency level, relevant help-centre articles, and the most suitable team for assignment.

Inputs and data sources:
Customer ticket text, account plan, recent support history, product-status data, and help-centre content.

Output or action:
A suggested classification and routing decision shown to the support agent before assignment.

Evidence:
Internal operations data shows that first assignment takes an average of 12 minutes, with frequent manual re-routing between teams.

Success looks like:
Lower time to first response and fewer tickets re-routed after initial assignment.

Constraints:
Support agents remain responsible for the final assignment. Some tickets may include credentials, personal data, or security incidents.
