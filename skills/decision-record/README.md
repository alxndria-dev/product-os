# Decision Record

A structured workflow for turning messy decision-making into a concise, durable record.

Use it after a meeting, Slack thread, workshop, architecture discussion, prioritisation session, or product review where a team needs to remember what was decided and why.

## Input

Provide any relevant material:

- Meeting notes or transcript
- Chat thread
- Problem statement
- Options considered
- Constraints
- Decision, if already made
- Owners and dates, if known

The skill works with incomplete context. If the discussion did not reach a decision, it should record that honestly rather than fabricating closure.

## Output

The record includes:

1. Decision status
2. Context and decision
3. Supported rationale
4. Options and trade-offs
5. Consequences and risks
6. Open questions
7. Owners and next actions

## What it does not do

- Pretend consensus exists
- Invent options, owners, dates, evidence, or agreement
- Hide dissent or meaningful uncertainty
- Turn a proposed action into a confirmed decision
- Replace formal governance, architecture review, or approval processes
